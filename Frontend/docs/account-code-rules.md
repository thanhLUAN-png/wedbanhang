# Ghi chú mã tài khoản mẫu

## Shipper ID

Khuôn dạng: `SP-MÃ_KHU_VỰC-ID_4_SỐ`.

Ví dụ `SP-BT-0012` nghĩa là:

- `SP`: tài khoản shipper.
- `BT`: khu vực Bình Tân.
- `0012`: ID tự tăng của bản ghi shipper trong database, nên mỗi mã luôn duy nhất.

## Seller ID

Khuôn dạng: `SL-MÃ_KHU_VỰC-ID_4_SỐ`.

Ví dụ `SL-BT-0001` nghĩa là:

- `SL`: tài khoản seller/chủ quán.
- `BT`: khu vực quán đăng ký (Bình Tân).
- `0001`: ID tự tăng của bản ghi seller trong database, nên mỗi mã luôn duy nhất.

## Mã quán ăn

Khuôn dạng: `MÃ_VÙNG-TỌA_ĐỘ_RÚT_GỌN-ID_4_SỐ`.

Ví dụ `BT-74101118-0001` gồm mã vùng `BT`, phần tọa độ rút gọn `74101118`, và ID quán `0001`. Phần ID đảm bảo không trùng ngay cả khi hai quán ở cùng vị trí.
